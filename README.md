My research portfolio
=======

Minimal academic physics portfolio built with Eleventy.

## Commands

```sh
npm install
npm run dev
npm run build
```

The source page lives at `src/index.njk`. Static files live in `assets/` and are copied into `_site/assets/` during the Eleventy build.

## Customize

- Replace placeholder publication titles with real citations and DOI links.
- Update `mailto:hello@rishabhps.com` with the preferred academic email.
- Add ORCID, Google Scholar, GitHub, and institutional profile links in the contact section.
